# Pandas Practice

A beginner-friendly project to learn and practice Python Pandas using the `orders.csv` dataset.

### Practice Goals
- Load and explore CSV data using Pandas
- Select specific columns and rows
- Filter data using conditions
- Add, update, and delete rows and columns
- Handle missing values and clean data
- Rename columns and change data types
- Group, count, and sort data
- Export cleaned data to CSV and Excel files

### Tools Used
- Python
- Pandas
- Jupyter Notebook

### Objective
Build a strong foundation in Pandas through simple, hands-on exercises and develop practical data manipulation skills for data engineering.
